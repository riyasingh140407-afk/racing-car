# 🏎️ Speed Racer — Arcade Racing Game

A fun and exciting browser-based racing game built using **HTML, CSS, and JavaScript**. Dodge incoming traffic, survive on the racing track, increase your score, and challenge yourself to beat your best performance!

## 🎮 About the Project

Speed Racer is a simple arcade-style car racing game designed for beginners who want to explore web development and game creation. It features an animated racing track, colorful enemy cars, smooth controls, collision detection, and a scoring system.

The game runs directly in your web browser, so no additional software or libraries are required to play.

## ✨ Features

- 🏁 **Interactive Gameplay** — Control your car and dodge incoming traffic.
- 🚗 **Enemy Traffic** — Avoid cars appearing in different lanes.
- 🎯 **Live Scoreboard** — Earn points by passing enemy cars.
- ⚡ **Increasing Difficulty** — The game becomes faster as your score increases.
- ⌨️ **Keyboard Controls** — Use the left and right arrow keys or A and D.
- 📱 **On-Screen Controls** — Move your car using the control buttons.
- 💥 **Collision Detection** — The game ends when your car hits another car.
- 🔄 **Restart Option** — Start a new race whenever you want.
- 🎨 **Neon-Inspired UI** — Enjoy a dark background with bright colors.
- 🌐 **Browser-Based** — No installation or external libraries needed.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Creates the game structure |
| CSS3 | Styles the interface and controls |
| JavaScript | Handles game logic, movement, traffic, and scoring |
| HTML Canvas | Draws the road and cars |

## 🚀 How to Run the Game

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three source files are in the same folder.
4. Open `index.html` in your web browser.
5. Click **START RACE** and enjoy the game!

## 🕹️ Controls

| Key / Button | Action |
|---|---|
| ⬅️ Left Arrow | Move the car left |
| ➡️ Right Arrow | Move the car right |
| A | Move left |
| D | Move right |
| LEFT / RIGHT buttons | Control the car |
| START RACE | Begin a new game |
| RACE AGAIN | Restart after game over |

## 🎯 How to Play

1. Click the **START RACE** button.
2. Move your car left or right to avoid enemy vehicles.
3. Pass enemy cars to earn points.
4. Stay alert as the speed gradually increases.
5. Avoid collisions and try to achieve a higher score.
6. If the game ends, click **RACE AGAIN** to play again.
